# Site vitrine GPXroad

Site statique (HTML + CSS, aucune dépendance). Ouvrir `index.html` dans un navigateur, ou servir le dossier tel quel (GitHub Pages, Netlify…).

Les écrans de téléphone sont dessinés en HTML/SVG (pas de captures) ; les liens App Store / Google Play sont fictifs tant que l'app n'est pas publiée (`#telecharger` dans `index.html`).
